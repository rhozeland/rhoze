# Copywriting

## Navigation labels (official, do not revert)
- "Find Work" — never "Opportunities". Links to `/community.html?view=open-calls`; the page heading and document title use the same wording.
- "Featured Projects" — never "Featured work". Links to `/projects.html`.
- Other nav items: Discover, Community, Book a project.

## Tone
Plain, direct sentences. No hype words, no crypto or investment language on public project pages.
